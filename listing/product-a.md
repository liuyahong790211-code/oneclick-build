## FAQ（商品页问答区，10 条）

**Q1：安装时弹"Windows 已保护你的电脑"，是病毒吗？**
不是。这是 Windows 对无代码签名软件的固定警告（原因见详情区"必须提前告诉你的两件事"）。按手册"更多信息 → 仍要运行"放行即可。包内组件（Ollama、AnythingLLM、Qwen3）均为知名开源项目。

**Q2：杀毒软件拦截/报毒怎么办？**
去杀毒软件隔离区恢复并信任，把安装目录加入白名单后重装。手册第五章有分步说明。

**Q3：我电脑只有 8GB 内存，能用吗？**
能，选"云端 API 模式"。8GB 跑不动本地 7B 大模型是实测结论，云端模式就是为这档机器准备的；文档向量化照样在本地跑。

**Q4：云端模式的 API key 费用谁出？**
你出，直接付给厂商（阿里/智谱/DeepSeek），我们不经手。日常问答每月通常几块钱。key 只保存在你本机，不上传任何地方。

**Q5：我的文档会被上传到网上吗？**
本地模式：不会，全程可断网。云端模式：提问内容会发给云端大模型（云端问答的工作原理），但文档向量化在本地完成。

**Q6：和免费自己装有什么区别？**
功能上用的都是开源软件；你买的是"不用折腾"——环境、模型、配置、中文优化全部打包调好，小白 1 小时内可用。自己装通常要踩好几天的坑（模型下载源、端口、配置项……）。

**Q7：支持 Mac / Linux 吗？**
不支持，本产品是 Windows-only。

**Q8：安装失败 / 装到一半出错了怎么办？**
安装程序自带失败回滚，日志在安装目录 `logs\` 文件夹。把日志+截图发给客服，我们帮你排查。模型下载支持断点续传，重跑安装包即可继续。

**Q9：可以退款吗？**
虚拟商品的退款规则以爱发电平台政策为准。购买前请确认你的电脑符合"系统要求"；拿不准的先咨询客服，我们帮你判断再决定买不买——**不合适的我们不建议你买**。

**Q10：以后换电脑 / 重装系统，还能用吗？**
可以。下载链接请妥善保存；换电脑后重新下载安装包再走一遍安装即可（同一买家免费重下）。
