## 一、安装前先看（3 分钟了解你在买什么）

### 1.1 这是什么

这是一个**一键安装包**，把下面这些原本需要你自己折腾好几天的东西，打包成一个安装程序：

- **Ollama**：本地大模型的运行环境（自动装好，不用你配置）
- **AnythingLLM Desktop**：知识库问答软件（中文界面，自动配好中文工作区）
- **Qwen3-8B 大模型**（本地模式）：通义千问 8B 量化版，约 5GB，安装时自动从国内 ModelScope 下载
- **预配置**：API key 自动生成、中文默认、遥测关闭、知识库工作区「我的知识库」自动建好

装完之后，你把自己的文档（PDF、Word、TXT 等）拖进知识库，就能像聊天一样问它文档里的问题——**所有数据都在你自己电脑上**。

### 1.2 两种运行模式（先选对，再安装）

| | 本地模式（推荐） | 云端 API 模式 |
|---|---|---|
| 适合 | 内存 ≥ 16GB 的电脑 | 8GB 等小内存电脑 |
| 大模型跑在哪 | 你自己电脑上（Qwen3-8B） | 国产大模型云端（通义千问 / 智谱 GLM / DeepSeek 任选其一） |
| 联网费用 | 不用联网付费 | **API key 的费用由你自己承担**（问答按量计费，日常用每月通常几块钱；key 在你选的厂商官网申请） |
| 文档向量化 | 本地（bge-m3，内存峰值约 1.85GB） | 本地（bge-m3，同左） |
| 安装下载量 | 约 5GB 模型下载 | 跳过模型下载，省时间省空间 |

**8GB 电脑请放心选云端模式**：我们实测过，8GB 机器本地跑 7B 级大模型会挤爆内存，但文档向量化本身在 8GB 上完全没问题。云端模式把"动脑"交给云端，检索文档的活还在本地。

> ⚠️ 云端模式需要你自己去厂商官网申请一个 API key（注册账号→控制台复制 key）。费用是厂商收的，不是我们收的，**39 元只是一键包的价格**。

### 1.3 系统要求

- Windows 10 / 11，**64 位**（32 位装不了，安装程序会直接拦下）
- 内存：本地模式建议 ≥ 16GB；云端模式 8GB 即可
- 磁盘：**剩余空间 ≥ 15GB**（安装包本体 + 约 5GB 模型 + 解压余量；安装程序启动时会自动检查，不够会提示你）
- 不需要管理员权限：**全程用户级安装，不会弹 UAC**（"你要允许此应用更改设备吗"那种窗口不会出现）

## 二、安装步骤（跟着点就行）

### 2.1 第 1 步：运行安装程序

双击你收到的 `AnythingLLM-OneClick-Setup.exe`。

**第一次双击会遇到 Windows 的安全警告，这是正常的**——因为我们没有买几千块一年的代码签名证书（这是已知的、写在商品页里的代价）。按下面操作放行：

1. 弹出蓝色窗口 **"Windows 已保护你的电脑"**
   [截图：smartscreen-1]
2. **不要点右上角的 ×**，点窗口下方的 **"更多信息"**
   [截图：smartscreen-2]
3. 展开后会出现发布者信息（会显示"未知发布者"，因为我们没签名），点 **"仍要运行"**
   [截图：smartscreen-3]
4. 安装程序正常启动，进入欢迎页

> 如果你的杀毒软件（360、火绒、Windows Defender 等）也弹了拦截提示，见第五章"杀毒软件拦截"。

### 2.2 第 2 步：欢迎页 → 许可协议 → 选择安装位置

1. 欢迎页：点"下一步"
2. 许可协议页：阅读后勾选"我接受"，点"下一步"
3. 安装位置：默认是 `%LOCALAPPDATA%\Programs\AnythingLLM-OneClick`（你自己的用户目录下），**建议不要改**，直接点"下一步"

### 2.3 第 3 步：选择运行模式（重要）

这一步会让你选 **"本地模式"** 还是 **"云端 API 模式"**（见 1.2 的对比表）。

- 安装页默认勾选"本地模式"；**8GB 电脑请手动改选"云端 API 模式"**
- **选错了不怕**：装完之后随时可以去「开始菜单 → 开源改装铺 → 切换运行模式」重新选（会按你的内存重新给出推荐）

选好后点"下一步"，正式安装开始。

> ☁️ 如果你选了云端 API 模式：需要填写一家国产大模型厂商（通义千问 / 智谱 GLM / DeepSeek）的 API key。key 在你选的厂商官网申请（免费注册账号→控制台复制）。
> 输入时 key 不回显（你看不到自己输了什么，这是防偷窥的正常设计）。key 只保存在你本机安装目录的配置文件里，**不会上传到任何地方**。
> ⚠️ 云端模式下 key 填写界面的最终形态**待 Phase 4 实测确认**（安装包与模式选择脚本的联调在 Phase 4 做），手册会在实测后更新截图。
> key 申请地址：阿里云百炼控制台 https://bailian.console.aliyun.com/ ｜ 智谱开放平台 https://open.bigmodel.cn/ ｜ DeepSeek 开放平台 https://platform.deepseek.com/

### 2.4 第 4 步：等待安装完成（本地模式约 20–60 分钟，取决于网速）

安装程序会按顺序自动执行，你只管看着进度条：

1. **静默安装 Ollama**（用户级，无感知；如果检测到你电脑已经装过 Ollama，会直接复用，不重复装）
2. **静默安装 AnythingLLM Desktop**（跳过约 2GB 的会议助手模型，省时间；已安装过则复用）
3. **下载大模型**（仅本地模式）：从 ModelScope 下载 `Qwen3-8B-Q4_K_M.gguf`（约 4.7GB），**支持断点续传**——中途断网/关机/杀掉安装程序都没关系，重新运行安装包会从断点继续，不会从头再来
4. **创建本地模型**：把下载好的模型注册进 Ollama（名字叫 `oneclick-qwen3-8b`）
5. **预配置 AnythingLLM**：等服务启动（最多等 3 分钟）→ 自动生成 API key → 建好中文工作区「我的知识库」→ 关闭遥测 → 注入防"思考过程外泄"的 system prompt

全部完成后点"完成"。开始菜单里会出现「开源改装铺」文件夹，里面有三个快捷方式：

- **AnythingLLM 问答**：日常使用点这个
- **切换运行模式**：想换本地/云端模式点这个
- **卸载一键包**：不想用了点这个（卸载时会问你要不要顺带卸载 Ollama 和 AnythingLLM Desktop，选"否"就保留它们）

## 三、第一次使用：导入你的文档

1. 点「开始菜单 → 开源改装铺 → AnythingLLM 问答」，启动软件（首次启动可能需要 1–2 分钟初始化，耐心等一下）
2. 进入后你会看到已经建好的工作区 **「我的知识库」**，点进去
3. 点工作区设置里的"上传文档"（或把文件拖进上传区），把你的 PDF / Word / TXT / Markdown 等文档传上去
4. 等待向量化完成（文档会被切块并在本地做向量化；bge-m3 在后台跑，内存占用约 2GB，属正常）
5. 回到聊天框，开始提问——比如"这份合同里违约金条款是怎么写的？"

**小技巧**：

- 上传前先确认文档不是扫描版图片 PDF（纯图片的 PDF 没有文字层，软件读不到内容；待 Phase 4 实测确认 OCR 支持情况）
- 文档越多、问题越具体，回答越准；先问"文档里有没有提到 X"，再追问细节
- 本地模式下，第一次提问时模型加载进内存需要几十秒，之后就快了

## 四、常见问答（FAQ）

**Q1：安装时弹"Windows 已保护你的电脑"，是病毒吗？**
不是。这是 Windows SmartScreen 对"没有代码签名证书"的软件的固定警告。我们为了把价格压到 39 元，没有购买每年几千块的签名证书——这是写在商品页里的已知代价。按 2.1 节"更多信息 → 仍要运行"放行即可。安装包里的每个组件（Ollama、AnythingLLM、Qwen3）都是知名开源项目。

**Q2：杀毒软件报毒/隔离了安装文件怎么办？**
见第五章"杀毒软件拦截"。

**Q3：我是 8GB 内存，能用吗？**
能，选"云端 API 模式"。本地 7B 大模型在 8GB 上跑不动是实测结论（不是我们没优化，是物理内存真不够），云端模式就是为这档机器准备的。文档向量化照样在本地跑，你的文档不会上传。

**Q4：云端模式的 API key 要钱吗？谁出？**
key 本身免费申请，按问答用量向厂商付费（日常问答每月通常几块钱）。**费用你直接付给厂商，我们不经手、不抽成**，39 元只是一键包的价格。key 只存在你本机。

**Q5：我的文档会上传到网上吗？**
本地模式：不会，全程断网可用（首次下载模型需要联网）。云端模式：提问的内容会发给云端大模型（这是云端问答的工作原理），但**文档向量化在本地**，key 只存本机。

**Q6：安装到一半断网了，要重来吗？**
不用。模型下载支持断点续传，重新双击安装程序，它会从断点继续。其他步骤失败会写日志并提示（见"故障排查"）。

**Q7：我想从本地模式换成云端模式（或反过来），要重装吗？**
不用。开始菜单 → 开源改装铺 → 切换运行模式，重新选一次即可。

**Q8：卸载干净吗？**
开始菜单 → 开源改装铺 → 卸载一键包，会删除我们创建的模型、配置和快捷方式。卸载时会单独问你要不要卸载 Ollama 和 AnythingLLM Desktop（如果你自己还会用它们，选"否"保留）。

**Q9：支持 Mac 吗？**
不支持，本产品是 Windows-only 路线。

**Q10：回答里偶尔出现 `<think>...</think>` 这样的标签，是坏了吗？**
这是 qwen3 系模型的已知小毛病（思考过程标签没藏好）。我们已经在 system prompt 和清洗逻辑里做了双保险；如果偶发出现，不影响答案正确性，重新问一次通常就好。待 Phase 4 实测确认新版 AnythingLLM 的隐藏效果。

## 五、故障排查

### 5.1 杀毒软件拦截

- **现象**：安装程序被删、被隔离，或安装到一半某个 exe "不见了"
- **处理**：
  1. 打开你的杀毒软件 → 隔离区/恢复区 → 找到被隔离的文件 → 选择"恢复并信任"
  2. 把安装包所在目录和安装目录（`%LOCALAPPDATA%\Programs\AnythingLLM-OneClick`）加入杀毒软件的**白名单/排除项**
  3. 重新运行安装程序
- 常见误报点：`OllamaSetup.exe`、`AnythingLLMDesktop.exe`、内嵌 Python 的 `python.exe`（这些都是正常组件）

### 5.2 端口被占用（11434 / 3001）

- **现象**：安装卡在"等待 Ollama 服务"或"等待 AnythingLLM 服务"，最后超时失败
- **原因**：11434（Ollama）或 3001（AnythingLLM）端口被其他程序占了
- **处理**：
  1. 以管理员身份打开 CMD，运行 `netstat -ano | findstr 11434`（或 3001），记下最后一列的 PID
  2. 任务管理器 → 详细信息 → 找到该 PID 的进程，确认不是你正在用的重要程序后结束它
  3. 重新运行安装程序

### 5.3 模型下载失败

- **现象**：进度条长期不动，或提示"下载失败（退出码 2）"
- **处理**：
  1. 先检查网络：浏览器能打开 https://modelscope.cn 吗
  2. 安装程序会自动重试 8 次（指数退避），别急着关
  3. 实在下不动：直接重新运行安装程序，断点续传会接着下（已下载的部分在安装目录 `models` 下，不会丢）
  4. 详细日志在安装目录 `logs\download.log`，联系客服时把这个文件发给我们

### 5.4 AnythingLLM 服务起不来（3001 超时）

- **现象**：卡在"等待 AnythingLLM 服务（127.0.0.1:3001）就绪"，180 秒后失败
- **处理**：
  1. 手动双击启动一次 AnythingLLM（开始菜单里找），看能不能打开界面
  2. 如果手动能开：关掉它，重新运行一键包安装程序走完预配置
  3. 如果手动也打不开：把安装目录 `logs\` 下的日志发给客服

### 5.5 安装失败回滚

安装程序任何一步失败都会**自动回滚**（删除本次写入的配置和已创建的模型），并弹窗告诉你日志位置（安装目录 `logs\`）。注意：Ollama 和 AnythingLLM Desktop 本体不会被自动删掉（怕误删你原本就装好的版本），如需清理请用"卸载一键包"或控制面板。

### 5.6 联系客服时请提供

1. 安装目录 `logs\` 文件夹打包（`ollama_setup.log` / `download.log` / `preconfig.log` 看哪个步骤出的错）
2. 你的 Windows 版本和内存大小（设置 → 系统 → 关于里能看到）
3. 你选的是本地模式还是云端模式
4. 出错时的截图
