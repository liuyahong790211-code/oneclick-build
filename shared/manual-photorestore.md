# 老片修复一键包 · 用户手册

> 版本：v1.0.0 ｜ 出品：开源改装铺 ｜ 适用：Windows 10 / 11 64 位
>
> ⚠️ **开篇先说清楚（不让你有错误预期）**：
> **视频修复功能必须搭配 NVIDIA 独立显卡（建议 6GB 以上显存，如 RTX 3060 级别）**。
> 没有 N 卡（核显 / AMD 卡 / 老机器）的用户：**照片修复功能完整可用**，视频修复按钮会自动禁用并弹窗说明原因——这是设计好的，不是 bug。
> 为什么：视频修复是逐帧超分，CPU 处理 1 分钟 720p 视频理论上需要数天，实际不可用（实测数据，见商品页）。我们宁可直接禁用，也不让你干等。

## 一、安装

### 1.1 系统要求

- Windows 10 / 11，64 位
- **照片修复**：无显卡要求，普通电脑就能用（CPU 跑，速度见 4.2）
- **视频修复**：NVIDIA 独立显卡 + **6GB 以上显存**（硬门槛，低于 6GB 会自动禁用）
- 磁盘空间：建议剩余 ≥ 10GB（安装包 + 模型 + 输出文件）
- 不需要管理员权限：**全程用户级安装，不弹 UAC**

### 1.2 安装步骤

1. 双击 `PhotoRestore-OneClick-Setup.exe`

2. **SmartScreen 警告放行**（和产品 A 一样，我们没有购买代码签名证书）：
   - 弹出 **"Windows 已保护你的电脑"** → 点 **"更多信息"** → 点 **"仍要运行"**
   [截图：smartscreen-1]
   [截图：smartscreen-2]
   [截图：smartscreen-3]

3. 选择安装位置（默认 `%LOCALAPPDATA%\Programs\PhotoRestore`，在你自己的用户目录下，建议不改）→ 点"安装"

4. 安装程序会自动：解压程序文件 → 安装 torch（CPU 版，随包内置，不联网）→ 写入开始菜单和桌面快捷方式 → 注册卸载信息

5. 完成后点"完成"。桌面和开始菜单「老片修复一键包」里都会有快捷方式。

> 模型（64MB 超分权重）**已经内置在安装包里**，安装后不用再下载模型，不存在"装完还要下东西"的坑。

### 1.3 首次启动：显卡检测弹窗（先看这个）

第一次打开软件，会先做一次显卡检测，然后你会看到**两种情况之一**：

- ✅ **情况一：有符合要求的 N 卡**（6GB+ 显存）
  顶部会显示"检测到 XXX（显存 XXGB），视频修复功能可用"，照片/视频两个模式都能点。

- ⚠️ **情况二：无 N 卡，或显存不足 6GB**
  会弹一个警告框，写明原因（未检测到 NVIDIA 显卡 / 显存不足），并告诉你照片修复不受影响。同时"视频修复"单选框变灰点不了。
  **这不是安装失败，这是产品设计**——请直接用照片修复功能。

## 二、照片修复（所有人都能用）

### 2.1 操作步骤

1. 打开软件，确认顶部选中的是 **"照片修复"** 模式
2. 把要修复的照片**拖进中间的文件列表**（如果拖拽没反应，点下方的"添加文件"/"添加文件夹"按钮——拖拽是可选功能，按钮添加效果完全一样）
   - 支持格式：`.png` `.jpg` `.jpeg` `.bmp` `.webp` `.tiff`
   - "添加文件夹"会自动扫描子目录里的所有图片
3. （可选）**输出目录**：默认是"图片"文件夹下的 `PhotoRestore`，点"选择…"可以改
4. 点 **"开始处理"**，看着进度条和日志走就行
5. 处理完的文件名是 `原文件名_4x.png`，**放大 4 倍**，存在你设的输出目录里

### 2.2 批量队列

- 一次加几十上百张都没问题，软件会按顺序一张张处理
- 列表里可以**选中某张 → 上移 / 下移**调整顺序，**删除选中**去掉不想修的，**清空**全部重来（处理中不能清空，先点"停止"）
- 每张的状态会实时显示：等待 → 处理中 → 完成
- 中途想停：点"停止"，当前这张处理完就停下，已完成的不会丢

### 2.3 速度参考（实测数据，非估计）

- CPU 修照片：以 160×120 放大到 640×480 为例，双核 CPU 约 **7 秒/张**（实测）
- 大照片会自动分块处理，更慢一些，属正常——去喝杯水，回来就好
- 照片修复**不需要显卡**，CPU 就行

## 三、视频修复（需要 N 卡 6GB+）

### 3.1 操作步骤

1. 打开软件，顶部切换到 **"视频修复"** 模式
   （如果这个选项是灰的，说明你的显卡不符合要求，回看 1.3——照片修复照常用）
2. 添加视频文件（支持 `.mp4` `.mov` `.avi` `.mkv` `.m4v`），可批量
3. **第一次跑视频任务**时，软件会自动从**国内镜像**下载安装 GPU 版 torch（约 2GB，只此一次，之后不用再下）。这一步可能需要十几分钟，请保持联网、不要关软件
4. 点"开始处理"，进度条会显示"视频 1/3：第 120/1800 帧"这样的实时进度
5. 输出 `原文件名_4x.mp4`：**分辨率放大 4 倍**，**原音频保留**，软件最后会自动做一次音画同步校验

### 3.2 耗时参考（诚实区间，spike 实测外推）

| 视频 | RTX 3060（12GB）级别 | 说明 |
|---|---|---|
| 1 分钟 720p | **约 9–15 分钟** | 逐帧超分 + 合成，属正常 |
| 1 分钟 1080p | 约 30–60 分钟 | 像素量是 720p 的 2.25 倍（待 Phase 4 真机确认） |
| 更长/更高清 | 按比例往上加 | 建议先拿 10 秒片段试修，确认效果再跑全片 |

> 这是 AI 超分的正常速度：每一帧都要过一遍神经网络。介意慢的请三思再买——我们把丑话说在前面。

### 3.3 关于"只修人脸"的说明（诚实告知）

本产品是 **Real-ESRGAN 单引擎**：整张画面统一做超分清晰化。
**不含人脸专项增强模块**（GFPGAN 因权重许可冲突未解决，我们永久不捆绑，这是合规选择）。
实际效果：人脸会随着整体清晰度提升而变清楚，但不会像"换脸级"修复那样单独重塑五官。买之前请建立正确预期。

## 四、常见问答（FAQ）

**Q1：安装时弹"Windows 已保护你的电脑"，是病毒吗？**
不是。无代码签名证书的软件都会遇到这个警告（原因见 1.2）。按"更多信息 → 仍要运行"放行即可。核心组件是开源的 torch + 自研推理代码 + ffmpeg。

**Q2：我没有 N 卡，能买吗？**
能，但你要清楚：**你只能用照片修复功能**，视频修复按钮是灰的。如果你买的主要目的是修老视频、且电脑没有 N 卡，**建议不要买**——我们不想赚这种错位预期的钱。

**Q3：我是 AMD 显卡 / 笔记本核显，能修视频吗？**
不能。视频修复目前只支持 NVIDIA 显卡（CUDA 生态），这是硬门槛。照片修复不受影响。

**Q4：我的 N 卡是 4GB 显存，能修视频吗？**
软件会判定为"显存不足"并禁用视频功能（6GB 是建议门槛，低于它强行跑可能中途崩溃）。照片修复正常用。

**Q5：照片修复效果有多好？**
Real-ESRGAN x4 级别的超分：模糊、压缩痕迹、低分辨率会有明显改善；但**已经完全糊成马赛克、一点信息都没有的区域，AI 变不出细节**——这是所有超分技术的共同边界，不是本产品独有。

**Q6：视频修复后音频还在吗？音画会错位吗？**
在。管线最后一步是"原音频混入 + 音画同步校验"，AAC 编码本身会带来约十几毫秒的自然偏差，属正常范围，校验通过才会标记完成。

**Q7：支持 Mac 吗？**
不支持，Windows-only。

**Q8：杀毒软件把程序文件隔离了怎么办？**
去杀毒软件的隔离区恢复并信任，把安装目录（`%LOCALAPPDATA%\Programs\PhotoRestore`）加入白名单后重装。

**Q9：卸载干净吗？**
开始菜单 → 老片修复一键包 → 卸载（或控制面板 → 卸载程序），会删除程序目录、快捷方式和注册表卸载信息。输出目录（`图片\PhotoRestore`）里的成品文件会保留，需要的话手动删除。

**Q10：输出目录能改吗？成品文件名能改吗？**
输出目录随时能改（界面上的"输出目录"栏）。成品文件名固定为 `原名_4x.png` / `原名_4x.mp4`，暂不支持自定义命名。

## 五、故障排查

### 5.1 拖拽文件没反应

- 拖拽依赖一个可选小组件，缺失时会自动降级——**直接用"添加文件"/"添加文件夹"按钮，功能完全一样**
- 以管理员身份运行软件时，拖拽可能被系统拦截（本软件不需要管理员权限，用普通方式打开即可）

### 5.2 GPU 版 torch 安装失败（视频模式首次运行）

- **现象**：日志显示"GPU 版 torch 安装失败"
- **处理**：
  1. 检查网络（需要从国内镜像下载约 2GB，保持网络稳定）
  2. 磁盘剩余空间是否 ≥ 5GB
  3. 关闭代理/VPN 后重试一次（某些代理会干扰大文件下载）
  4. 仍失败：把日志窗口的内容复制发给客服

### 5.3 视频处理中途崩溃 / 报错

- 大概率是显存不足：6GB 卡修 1080p 以上视频可能爆显存。**先拿短片段、低分辨率试**，确认能跑通再处理正片
- 把日志窗口最后 50 行发给客服

### 5.4 照片处理特别慢

- 正常现象：CPU 单张大照片分块处理本来就慢。批量任务建议**晚上挂着跑**，早上收成品
- 确认没有同时在跑其他吃 CPU 的程序

### 5.5 软件打不开 / 双击没反应

1. 去安装目录看 `launcher\start.pyw` 是否存在
2. 尝试用安装目录下便携 Python 手动启动看报错（联系客服时我们会指导你）
3. 杀毒软件隔离是常见原因，先查隔离区

### 5.6 联系客服时请提供

1. 日志窗口的完整内容（右键全选复制，或截图）
2. 你的显卡型号和显存大小（任务管理器 → 性能 → GPU 里能看到）
3. 你在用照片模式还是视频模式
4. 出错时的截图
